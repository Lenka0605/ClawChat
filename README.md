# ClawChat

本地 AI 群聊：你、Claude（Claude Code）、ChatGPT（Codex）、DeepSeek、GLM（智谱）和 Gemini（Google）在一个群里，一起在你的项目文件夹里干活。

- 全部跑在你自己的电脑上，用你自己的 Claude / ChatGPT / Google 账号，以及 DeepSeek、GLM、Gemini 的 API Key，不经过任何第三方服务器。
- Mac 和 Windows（10 / 11）都能用。
- ClawChat 本身没有第三方依赖，只需要 Node.js 22+，以及你想用的那几位：Claude Code、Codex、Antigravity CLI（订阅）或 Gemini CLI（API）；DeepSeek 和 GLM 都借 Claude Code 干活。

## 在 Windows 上安装（给同事看的）

1. 在 GitHub 页面点绿色的 **Code → Download ZIP**，下载后解压。
2. 把解压出来的 `ClawChat` 文件夹放到一个**以后不会挪动**的地方，比如 `D:\ClawChat`。
3. 双击文件夹里的 **`Install-Windows.cmd`**。如果弹出「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。
4. 安装程序会一步步问你，按回车就是默认选项。它会：
   - 装好 Node.js 和 Git（用 Windows 自带的 winget，中途可能弹出管理员授权，点「是」）；
   - 装好 Claude Code（Claude、DeepSeek、GLM 都靠它干活；只用 DeepSeek 或 GLM 的话不用登录 Claude 账号）；
   - 问你要不要装 Codex（群里的 ChatGPT，要有 ChatGPT 账号，不用的话直接回车跳过）；
   - 问你要不要装 Antigravity CLI（用 Google 个人订阅），或 Gemini CLI（用独立计费的 API Key）；
   - 接上 GitHub，以后可以一键在线升级；
   - 在桌面和开始菜单放一个 **ClawChat** 图标，然后打开它。
5. 用 DeepSeek / GLM：去 [platform.deepseek.com](https://platform.deepseek.com/api_keys)（DeepSeek，要先充值一点余额）或 [bigmodel.cn](https://bigmodel.cn/)（GLM）创建一个 API Key，然后在 ClawChat 左下角点「设置 → 程序与模型」，填进对应那一栏，点保存。Gemini 的用法见下面的「Gemini（Google）」。
6. 新建聊天，勾上想要的成员，就可以开始了。

以后双击桌面上的 **ClawChat** 就能打开。关掉窗口它会在后台接着干活；要彻底退出，在「设置 → 通用」里点「退出 ClawChat」。有新版本时「设置」上会亮一个小红点，到「软件更新」里点「立即升级」就行。

> 仓库是私有的话，同事的 GitHub 账号要先被加进仓库（Settings → Collaborators），才能下载和在线升级。

Windows 上和 Mac 的几处不同：

- 窗口是用 Edge 的「应用模式」打开的（没有地址栏，看起来就是一个独立软件），Edge 是 Windows 10 自带的。
- Claude Code 在原生 Windows 上没有沙盒（官方文档写明不支持）。「项目内放手干」时 Claude、DeepSeek、GLM 能改项目文件夹里的文件、跑命令，但命令能不能只动项目文件夹，要靠它们自觉（已经在提示词里交代过）。ChatGPT（Codex）有自己的 Windows 沙盒，ClawChat 会选不需要管理员权限的那种。
- HEIC 这类图片格式 Windows 转换不了，要先另存成 JPG / PNG；太大的图会先在本地缩小再发。

## 打开（Mac）

双击「应用程序」里的 **ClawChat**。关掉窗口不会退出，大家可以在后台继续干活；按 ⌘Q 才是真正退出，正在干的活也会一起停掉。

不想用应用窗口的话，也可以在这个文件夹里运行 `npm start`，然后用浏览器打开 http://127.0.0.1:7317 。

## 怎么用

- **点名**：`@Claude`、`@ChatGPT`、`@DeepSeek`、`@GLM`、`@Gemini`、`@所有人`。输入 `@` 会弹出成员菜单，比如打 `@c` 就会出现 Claude，按 Enter 或 Tab 填进去。输入框里和发出去的消息里，每位成员的 @ 都会显示成带头像的标签；在群里点一下消息里的 @ 标签，输入框里也会 @ 上它（接在你正在打的字后面）；@ 标签是一个整体：方向键会跳过整个标签，光标进不到中间；光标在 @ 后面时按一次退格（在前面时按 Delete）先选中整个 @，再按一次就删掉。输入框里 ⌘Z 撤销、⇧⌘Z 重做，插入或删掉的 @ 也能撤销。不点名时，默认**接着上一位**：发给群里最后说话的那位 AI（还没人说过话就大家一起），输入框上方的「不 @ 时 接着上一位（ChatGPT）」和输入框里的提示会写明这条会发给谁。以前默认是大家同时开工，常常刚发出去就得停掉不该开工的那几位（比如「合了发」只是对 ChatGPT 说的），所以改了；以前的群也换成了这个。「不 @ 时」也可以改成「大家同时开工」「大家依次回答」（后答的能看到前一位说了什么），或者只发给其中一位。@所有人 时大家同时开工，各自都知道别人也在干，需要对结果时会互相 @。改消息时（消息上的「编辑」）也能 @，和输入框里一样弹成员菜单、显示成带头像的标签。
- **接力**：成员之间可以互相 @，对方会被叫醒接着干活。你不说话时，连续接力到设定的轮数就自动停下来，等你发话。
- **图片**：点「图片」按钮，或者直接粘贴（⌘V）、拖进窗口。大家都能看到图片（用的模型看不了图时，只告诉它图片文件在哪）。HEIC 格式、太大或尺寸太大的图会自动转成 JPG。
- **私聊**：
  - 你找它：在群里点某位的头像（或右上角的头像），就能私聊它，其他成员看不到。它记得群里的所有事，你在私聊里定的事，它可以直接去群里落实。
  - 它找你：觉得其他成员的安排不合理，它可以直接在群里说，也可以私下找你。私聊会出现在左侧，标着「私聊 · 群名」。
  - 实现方式：AI 把只给你看的话写在 `<私聊老板>…</私聊老板>` 里；你私聊它时，它的回复默认也是私聊，要公开就写在 `<群聊>…</群聊>` 里；它没看过的群消息（别人之间在聊、没叫它）只当背景，回复照样留在私聊里。如果群里正好也有人 @ 了它，这一轮按群聊算，回你的那部分照样私下发给你，私聊里也会显示它「正在干活」。这些标签你看不到，ClawChat 会自动分拣。分身（本体在群里忙时先回私聊的那位）也一样，你让它去群里同步进度，它会发到群里。
  - AI 之间也能私聊：一位 AI 把话写在 `<私聊 DeepSeek>…</私聊>` 里，就只发给 DeepSeek，对方会被叫醒，回复默认也是私下回它；群里其他 AI 看不到。整段对话放在被找的那一位的私聊里：Claude 找 DeepSeek，Claude 的话、DeepSeek 的回复、之后的来回，都在你和 DeepSeek 的私聊里，Claude 的私聊里不会出现；反过来 DeepSeek 主动找 Claude，就在 Claude 的私聊里。名字一栏写着「Claude → DeepSeek · AI 私聊 · 今天 23:27」。AI 之间私聊和 @ 一样算一轮接力，受「最多连续接力」的轮数限制；关掉「互相 @ 接力」后，私聊不会叫醒对方，等对方下次轮到时才看到。
  - 私聊里 @ 别人，对方是收不到的。AI 在私聊回复里 @ 了别人、却没发到群里时，私聊里会提醒你，附一个「发到群里」按钮；不会自动转过去，因为私聊里也可能是在跟你说对方的事。AI 在私聊里的每条回复下面也都有「发到群里」按钮（↪），想把哪段话分享到群里点一下就行，群里会标着「从私聊转来」。
- **分身**：某位正在群里干活时你私聊它，不用等它干完——ClawChat 会复制一份它当前的记忆，开一个「分身」马上回你（消息上标着紫色的「分身」）。分身只能看、不能改文件，免得和手上的活打架；你让它动手的话，它会说干完手上的活就去做。群里另一位 AI 私下找一位正在忙的成员时也一样：对方的分身马上私下回它，不用等对方手上的活干完。本体干完后会看到分身聊了什么，答应过的事接着做，不会重复回复。
- **语言**：支持简体中文和 English。默认跟随系统：系统是中文就用中文，否则用英文；也可以在「设置 → 通用 → 语言」里固定选一种。换语言后整个界面（包括菜单栏、群里的提示）都会换过来，AI 也会改用这种语言回复。已经发出去的消息和提示保持原来的语言。
- **系统通知**：ClawChat 不在前台时，谁回了话、谁出错了，都会弹一条系统通知（同一个聊天只留最新一条），点一下直接打开那个聊天。第一次会问你要通知权限；不想要可以在「设置 → 通用 → 通知」里关掉。
- **搜索聊天内容**：左上角的搜索框除了按名字找聊天，也会在所有群聊、私聊的消息里找，命中的字会标出来；点一条结果就打开那个聊天、跳到那条消息。
- **滚动条和「回到最新」**：消息区右边的滚动条平时藏着，鼠标移到右边缘才出现，可以拖，也可以点。往上翻看旧消息时，右下角会出现一个「回到最新」按钮（↓↓），点一下回到最底下；翻上去期间来了新消息，按钮上会标出条数。
- **长对话不卡**：打开聊天时只画最近 80 条，往上翻快到顶时自动接上更早的，位置不会跳；「过程」展开时才画出来。几百条消息的聊天，打开、切换都很快。
- **草稿**：每个群聊、私聊的输入框各管各的。打了一半没发的字，切到别的会话不会带过去，切回来还在；关掉重开也还在。
- **单聊**：新建聊天时只勾选一位成员，就是和它单独聊。
- **帮你装 Claude Code**：Claude、DeepSeek、GLM 都要借 Claude Code 干活（DeepSeek、GLM 只借它的工具，不用登录 Claude 账号）。打开 ClawChat 时如果发现这台电脑还没装，会弹窗说明并问你要不要现在装；填了 DeepSeek / GLM 的 Key、或者建了有它们的群时，没装也会再问一次。点「帮我安装」就用 Anthropic 官方的安装程序装在你自己的用户目录里（Mac：`curl -fsSL https://claude.ai/install.sh | bash`；Windows：`irm https://claude.ai/install.ps1 | iex`），不用管理员密码，装好马上能用。群里「找不到 claude 命令」的报错下面、「设置 → 程序与模型」里 Claude Code 那一行，也都有「安装 Claude Code」按钮。
- **只显示能用的成员**：新建聊天、欢迎页里，这台电脑上用不了的成员默认不出现。比如只装了 Claude Code 给 DeepSeek 借用、自己没登录 Claude 账号，就看不到 Claude；没装或没登录 Codex，就看不到 ChatGPT；DeepSeek、GLM 没填 Key 也先藏着。要加的话，点成员下面的「还有 xx 没装好或没登录，显示出来」。已经在群里的成员照常显示。
- **多开成员**：同一位可以再开一个独立的成员，比如没有 Claude 时多开一个 **ChatGPT2**。在「设置 → 程序与模型 → 多开成员」里选好是谁、点「开一个」就行，编号从 2 号往后排（最多 9 号）。多开的成员和本体用同一个程序和账号，但有自己的记忆（会话）、模型和思考强度、私聊，和本体分头干活；头像是本体的头像，右下角标着几号。在群里用 `@ChatGPT2` 叫它，`@ChatGPT` 叫的还是本体；AI 之间私聊写 `<私聊 ChatGPT2>…</私聊>`。删掉多开的成员时，它会从所有群里退出，聊天记录还在（和它的单聊要先删掉）。
- **停止**：一位在干活时，输入框上方右边显示「停止 Claude」；好几位同时在干时，合成一个红色的「全部停止」。要单独停某一位，点它「正在干活」气泡里的「停止」，不影响别人。窗口窄时，输入框上方的 @ 按钮会只留头像，保证这一行不会挤成两行。它们启动的命令也会一起停掉。
- **换新会话**：哪位卡住了、或者会话太重了，可以给它换一个新会话。三个地方都能换：干活气泡上方的「换新会话」（会结束手上这一轮）、「群设置 → 会话（记忆）」、以及群里「图片太多」提醒下面的按钮。点了会弹出一个小窗，选谁来给它交代情况：
  - **群里另一位 AI**：它会在群里 @ 它，把要做什么、做到哪了、文件在哪、有什么要求重新交代一遍，交代完它接着干。默认选的是上一次给它派活的那位（标着「上次给它派活」），想换别人就点别人；
  - **不用交代**：它直接带上最近 40 条聊天记录自己接着干（空着的话，下次叫它时生效）。没有 AI 给它派过活时默认选这个；
  - **我自己来交代**：手上的活先停下，输入框里自动 @ 上它，你说完它再开新会话接着干；
  - 不管哪种，它都会拿到一份完整聊天记录的文件，项目文件夹里的东西都还在，只是之前聊的细节要它自己翻记录。
- **卡住了**：某位两分钟没有任何动静，它的气泡里会提示「可能卡住了」，并给出「换新会话重来」按钮。分身卡住不会挡住本体，群里的新消息照样马上处理。

### 让 ChatGPT 做图时，什么时候要给它换新会话

ChatGPT（Codex）每看一张图，包括它自己刚做出来的图，都会把整张图原样存进会话；之后每一轮都要把这些图整个重新发给 OpenAI。一张海报 2～6MB，看几次就攒起来了：

| 会话里存的图片 | 状态 | 怎么办 |
|---|---|---|
| 8MB 以下 | 正常 | 不用管 |
| 8MB 左右 | 开始变慢 | 群里会提醒一次，附「给 ChatGPT 换新会话」按钮。这批活告一段落时点一下 |
| 13MB 以上 | 随时可能慢到像卡住（实测超过 17MB 时几分钟都没有回应） | 群里会再提醒一次，建议马上换 |
| 两分钟没有任何动静 | 多半已经卡住 | 点气泡里的「换新会话重来」 |

- 「群设置 → 会话（记忆）」里能看到每一位的会话记了多少：记忆用了百分之几（比如「记忆已用 47%（46.9 万 / 100 万 token）」，下面一根细条，到七成变橙、八成五变红），ChatGPT 还会显示存了多少图片。每一位下面写着什么时候换比较合适：
  - Claude：用到七成左右，或一件大事做完时。越长每轮越慢、越费额度；快满时它会自动压缩记忆，要等一两分钟，细节也会丢。
  - ChatGPT：用到七成左右，或图片到 8MB 时（一批图做完就换）。
  - DeepSeek：上限很大（100 万 token），不容易满；一件事做完、或用到七成左右时换。越长每轮越慢、越费钱（大多走缓存，花费很低）。
  - Claude 的上限要等它更新后回过一次话才知道（Claude Code 每轮结束时会报），在那之前只显示用了多少 token。
- 会话里的图片到 8MB，顶部 ChatGPT 的按钮上会一直亮着一个橙点（13MB 以上变红点），点开菜单最上面写着原因，下面就是「换新会话」，换完点就消失。
- 最省心的做法：一批图做完、开始下一批之前，主动换一次。
- ClawChat 已经要求 ChatGPT 看图前先缩小成 1200 像素以内的副本，能慢很多才攒满；但它偶尔还是会直接看原图。
- 只有 ChatGPT 有这个问题。Claude、DeepSeek、GLM 用的是 Claude Code，它会自己缩小图片、自动压缩会话。
- **回复**：鼠标移到一条消息上，点旁边的回复按钮。回复 ChatGPT 的消息时只有 ChatGPT 回答，回复 Claude 的消息时只有 Claude 回答；回复时又 @ 了别人，就按 @ 的来。你的消息上会带着被回复的原话，点一下就能跳回去。
- **文件路径**：回复和「过程」里提到的文件（比如 `output/海报-v6.png`，或者「[中文版](/Users/…/海报.png)」这样的链接），点一下就在访达里打开它所在的文件夹并选中它；图片文件鼠标移上去会弹出缩略图，不用打开就知道是哪张。「正在干活」气泡里的过程也一样。AI 常常只写文件名（比如前面说了「图片都在 `design-requests/dark-mode-art` 里」，后面只写 `图片对比.html`）：项目根目录下找不到时，ClawChat 会先到同一条消息里提到的文件夹下找，再在整个项目文件夹里按名字找（跳过 node_modules、build 这类文件夹），找到好几个就取最近改过的。项目里确实没有的（比如 `xxx-dark-1024.webp` 这种举例的写法、还没生成的文件），就显示成普通文字，不会点了才说找不到。
- **气泡颜色**：每位 AI 的气泡各有颜色，贴近各自的官方配色：Claude 是暖象牙色，带一点陶土橙；ChatGPT 是中性的石墨灰，边上带一丝 OpenAI 绿；DeepSeek 是淡淡的冰蓝；GLM 是淡紫；Gemini 是淡青。都有上亮下暗的渐变、顶部高光和同色光晕，深色模式下各有一套深色版本。
- **消息上的按钮**（仿 ChatGPT，鼠标移到消息上就出现在气泡下面）：
  - 你的消息：发送时间（24 小时制，精确到秒）、**复制**、**编辑**、回复。编辑是在气泡里直接改，改好按 Enter 或「发送」：大家已经看过原来那条了，所以改好的会作为新消息发出，上面标着「修改了：原话」，AI 也会知道以这条为准；原来的图片会一起带上。Esc 取消。
  - AI 的回复：**复制**（复制 Markdown 原文）、**朗读**（用系统自带的语音，有中文就挑中文语音；再点一下停止）、回复、发送时间。
- **过程**：每条回复下面的「过程」可以展开，看它跑了哪些命令、改了哪些文件；正在干活时也能点「展开过程」实时看全部步骤，ChatGPT 的思考摘要会以 💭 显示。
- **[PASS]**：跟自己无关的消息，它们会回 [PASS]，群里不显示。

## 记忆

- 退出再打开，所有聊天记录、私聊和图片都还在。
- 每位各自接着原来的会话（Claude、DeepSeek、GLM 用 Claude Code 的 `--resume`，ChatGPT 用 Codex 的 `exec resume`，Gemini 用 `agy --conversation` 或 Gemini CLI 的会话文件），记得之前聊过什么、做过什么。会话找不到时，会带上最近 40 条聊天记录开一个新会话。
- 退出时还在干活的那一轮：如果是你点了更新或重启，重新打开后它会自动接着做（先看看做到哪了），群里会说一声；如果是退出了应用（⌘Q、关机），下次打开会提示「被打断了」，附一个「让它接着做」按钮。
- 有 AI 在干活时点更新或重启，会先问你：可以选「等干完再重启」，它们这一轮都干完后自动重启（左下角的按钮会变浅、外面一圈在转，点它可以马上重启或者不重启了）；也可以「现在重启」，重启后自动接着做。
- 上下文快满时，Claude、DeepSeek、GLM 会自动整理（压缩）记忆，要一两分钟、中间没有别的动静。这时干活气泡上写的是「正在整理记忆」，过程里也会说明，不会被当成卡住。
- 出错的那一轮不算处理过，下次叫到它时，会把没处理的消息重新交给它。
- **上下文满了**：Claude Code 和 Codex 快满时会自己压缩，一般不用管。万一还是报「上下文满了」，ClawChat 会自动给它换一个新会话，带上最近 40 条聊天记录接着干，并在群里说一声；更早的完整记录会写成一个文件给它看，里面只有它本来就能看到的内容（群聊 + 它自己和你的私聊），其他成员和你的私聊不在里面。换了新会话还超的话，多半是这次一下子发了太多内容，会提示你分几次发。

## DeepSeek

- DeepSeek 没有自己的命令行工具，ClawChat 让它**借 Claude Code 干活**：把 Claude Code 的接口换成 DeepSeek 的 Anthropic 兼容接口（这是 DeepSeek 官方文档推荐的接法），所以它和 Claude 一样能读写文件、跑命令、联网搜索。
- 需要：装好 Claude Code（不用登录 Claude 账号）+ 在「设置 → 程序与模型」里填 DeepSeek 的 API Key。Key 只存在本机 `~/.clawchat/config.json`（只有你自己能读），也可以用环境变量 `DEEPSEEK_API_KEY`。
- 它用单独的 Claude Code 配置目录（`~/.clawchat/deepseek/claude-home`）：不会用到你 Claude 账号的登录，也不沿用你给 Claude 设的模型和思考强度，会话记录也分开放。
- 模型列表直接读 DeepSeek 的模型目录，出了新模型会自动出现。现在有 **DeepSeek Flash**（默认，快、便宜，能看图）和 **DeepSeek V4 Pro**（更强，不能看图）。选了看不了图的模型时，图片只告诉它文件在哪。
- API Key 填错或者余额不足，会马上提示，不会一直重试。

## GLM（智谱）

- GLM 是独立成员，可以和其他成员一起加入群聊，也可以单聊。用 `@GLM` 或 `@智谱` 点名。
- 先装好 Claude Code（只用 GLM 不必登录 Claude 账号），再到 [智谱开放平台](https://bigmodel.cn/) 创建 API Key，在「设置 → 程序与模型 → GLM」中填写并保存。不要把 Key 发进群聊。
- GLM 和 DeepSeek 共用 Claude Code 的工具能力，但走各自的 Anthropic 兼容接口、Key 和模型；GLM 的 Claude Code 配置、会话保存在 `~/.clawchat/glm/claude-home`，不会混用 Claude 或 DeepSeek 的登录和记忆。
- Key 只保存在本机 `~/.clawchat/config.json`，也可通过 `GLM_API_KEY` 环境变量提供。当前使用智谱开放平台接口；其他套餐或专用接口的 Key 能否使用，以对应平台的接口权限为准。
- 顶部成员按钮可以切换 GLM 模型。内置模型清单不会自动更新；有新模型时可用模型菜单中的自定义模型功能添加。当前清单没有标注能看图的 GLM 模型，图片会作为文件路径交给它；需要看图时可以交给群里其他成员。

## Gemini（Google）

个人订阅使用 **Antigravity CLI（`agy`，1.4.10 或更新）**。Google 已在 2026 年 6 月 18 日停止为个人免费账号、Google AI Pro 和 Ultra 提供 Gemini CLI 的 Google 登录服务。[官方停用公告](https://developers.google.com/gemini-code-assist/docs/deprecations/code-assist-individuals)

1. macOS / Linux 按[官方安装说明](https://antigravity.google/docs/getting-started/?tab=cli)安装：`curl -fsSL https://antigravity.google/cli/install.sh | bash`。Windows 安装程序也可选装。
2. 在终端运行 `agy`，登录购买订阅的同一个 Google 账号，完成首次设置，然后退出。已安装但低于 1.4.10 的版本，先运行 `agy update` 更新，再刷新 ClawChat 程序列表。
3. ClawChat 的 Gemini API Key 留空，同时不要设置 `GEMINI_API_KEY` 环境变量；刷新程序列表，新建聊天时勾上 Gemini。已有群可以在群设置里添加。用 `@Gemini` 或 `@谷歌` 点名。

订阅入口每轮都会通过 `--settings` 强制设置 `useG1Credits: false`，不改用户的全局配置。订阅额度用完时等待恢复，不自动扣额外 AI 点数，也不切换到 API。Pro / Ultra 的额度按工作量计算，有五小时与周限额，恢复时间可在 `agy` 中用 `/usage` 查看。[官方额度说明](https://antigravity.google/docs/plans/)、[点数设置](https://antigravity.google/docs/cli/credits/)

**API 是另一条独立入口**：安装 `npm install -g @google/gemini-cli@latest`（需要 0.66.0 或更新），从 [Google AI Studio](https://aistudio.google.com/apikey) 创建 Key，填到「设置 → 程序与模型 → Gemini」。只要填了 Key，就明确使用 Gemini CLI 的 API 路径，不使用个人订阅额度。API 有独立免费档和付费档，按 API 的额度与计费规则使用。设置里的 Key 优先，其次是 `GEMINI_API_KEY` 环境变量；清空并保存会删掉本机保存的 Key，但不会删除环境变量。

- 两种入口不会自动互相回退。主动切换订阅 / API 时，旧会话文件保留；下一轮自动开新会话，带上最近的聊天记录恢复。更早的细节可从完整聊天记录查找，也可以先用「换新会话」请同事交代情况。
- 订阅默认固定使用 Gemini 3.8 Flash，避免沿用 `agy` 里选过的其他厂商模型；可在模型菜单选择 Gemini 4 Argon 等模型。模型清单是预置选项，实际权限取决于订阅与 CLI 版本；自定义模型用 `agy models` 列出的 slug。
- 订阅的完整记忆由 `agy` 保存在自己的数据目录里，ClawChat 保存准确的会话 ID，退出重开后继续同一会话。备份时同时保留 `~/.gemini/` 和 ClawChat 数据目录。`~/.clawchat/gemini/antigravity/` 保存最近成功回合的文字备份，供分身参考；分身另开独立会话，不直接续接本体，也不把私聊写回本体。文字备份最多保留最近 16 万字符，不能当作完整会话克隆。
- API 入口在 `~/.clawchat/gemini/sessions/` 归档成功后的完整会话，备份 ClawChat 时一起保留。记忆归档失败时不会重跑已执行的命令，而是提示并在下一轮从聊天记录恢复。旧版 Google 登录缓存如需清除，退出 ClawChat 后删除 `~/.clawchat/gemini/auth/`。
- 两种入口都能读写文件、执行命令并读取图片。「只读讨论」和分身禁止命令、写文件与 MCP。订阅分身从独立空目录启动，项目作为附加目录供读取；它参考的是上述文字备份和本体最近进度。
- 订阅的「项目内放手干」使用原生沙盒与 `proceed-in-sandbox` 策略：只自动执行沙盒内命令，沙盒不可用或需要越界时不自动放开；无界面模式下需批准的操作会被拒绝，模型可能说明某步没有执行。可查看过程，不能把 CLI 正常退出等同于所有工具操作都成功。Windows 沙盒需要 Windows 11 24H2 及 2026 年 8 月更新或更高版本。[官方权限说明](https://antigravity.google/docs/sandbox/)
- API 的项目模式要求 Gemini CLI 沙盒。macOS 使用官方 `permissive-open`：项目、附加目录、必要的缓存和临时目录可写，允许联网；其他系统按 CLI 提示配置沙盒。普通任务会信任项目并读取 `.gemini/settings.json`，包括项目 hooks；只读和分身从空目录启动。
- `agy` 沿用用户的原生认证、项目设置和 hooks，请只打开信任的项目；ClawChat 的会话级权限与计费设置不修改用户全局文件。CLI hooks 是用户配置的程序，不属于模型工具权限限制范围。
- 更新订阅 CLI 用 `agy update`；更新 API CLI 用 `npm install -g @google/gemini-cli@latest`，之后在 ClawChat 刷新程序列表。

## 模型

- 聊天窗口顶部每位成员有一个小按钮，显示它现在用的模型和思考强度，点开就能换，从下一轮开始生效。换模型不影响记忆，会话照样接着。
- 模型旁边是**思考强度**：Claude 有 低 / 中 / 高 / 超高 / 最高 五档；ChatGPT 的档位取决于模型，多数是 低 / 中 / 高 / 超高 / 最高 / 极限（极限会自动把任务拆给帮手），Luna 系列没有极限。「默认」跟随 Claude Code / Codex 自己的设置。换了模型、新模型又不支持原来的强度时，会自动退回默认。
- **私聊里单独设置**：在私聊里点顶部的按钮换模型、思考强度或速度，只改私聊，群里的设置不变（菜单最上面会写明）。私聊里没单独改过的项跟着群里走；想恢复，菜单里点「恢复成和群聊一样」。
- 切换后群里会提示一条（私聊里改的，提示只出现在私聊里），每条回复的名字旁边会标出这次实际用的模型，比如 `Fable 5.1`、`GPT-6-Astra`。
- **ChatGPT 的速度**：支持快速模式的模型（比如 GPT-6.1 Sol、GPT-6 Astra），菜单里多一组「速度」，也可以在「群设置 → 速度」里改。默认是**标准**；**快速**大约快 1.5～2 倍（按 OpenAI 模型目录里每个模型自己的数据显示：GPT-6.1 Sol、GPT-6 Astra 写的是 2 倍，其它多是 1.5 倍；ChatGPT 应用里对所有模型都统一写 1.5 倍），但按 OpenAI 官方文档，会按标准速度的 **2.5 倍**消耗 ChatGPT 订阅里的额度（另外买的点数按 2 倍算），所以打开前会再问你一次。开着快速模式时，顶部 ChatGPT 的按钮上有一个橙色的「⚡快速」。ClawChat 每次叫 ChatGPT 都会明确指定速度，不跟着你自己 Codex 配置里的 `service_tier` 走。
- Claude 可选 Fable、Opus、Sonnet、Haiku，用的是别名，Claude Code 会自动对应到最新版本。
- ChatGPT 的列表直接读 Codex 的模型目录，只列出你账号能用的模型。

### 出了新模型（比如 GPT-7）怎么用

1. **等它自己出现**：ClawChat 每 5 分钟重新读一次模型目录，你切回窗口时也会读一次。只要 Codex 的目录里有了新模型，下拉框里就会多出来，不用重启。
2. **没出现就点「更新」**：新模型常常要新版本的命令行才看得到。点左下角 Codex（或 Claude Code）旁边的「更新」，更新完列表会自动刷新。
3. **还没有就自己填**：选下拉框最下面的「自定义模型…」，填上模型名。ClawChat 会先用它试着回一句话：能用才切换，用不了会显示原因，不会把群弄坏。

## 设置与在线升级

点左下角的「设置」，或者按 ⌘,：

- **通用**：主题（浅色 / 深色 / 跟随系统）、语言、聊天记录放在哪。
- **程序与模型**：Claude Code、Codex、Antigravity CLI / Gemini CLI 的版本和「更新」按钮，DeepSeek、GLM、Gemini 的 API Key，以及现在能用的所有模型。
- **更新**：当前版本，「检查更新」和「立即升级」。升级会从 GitHub 拉取最新代码、重新打包，然后自动重启。Mac 上打包时用本机固定的签名证书（第一次打包时自动生成，放在 `~/.clawchat/signing`，不碰登录钥匙串），系统认得升级后还是同一个应用，给过的权限不用再授权一次。聊天记录和记忆不受影响；正在干的活重启后会提示你接着做。ClawChat 每小时自动检查一次，有新版本时，左下角「设置」右边会出现一个蓝色的更新按钮，点它确认后就会更新并重启。

菜单栏里的「ClawChat → 检查更新…」也可以直接检查。

需要 Node.js 22+、Xcode 命令行工具（`xcode-select --install`），以及你想用的那几位的命令行：登录好的 Claude Code（Claude、DeepSeek、GLM 都要）、Codex（ChatGPT）、Antigravity CLI 或 Gemini CLI（Gemini）。

```sh
gh repo clone Lenka0605/ClawChat   # 或 git clone
cd ClawChat

```

Claude、ChatGPT、Gemini 的头像用的是本机官方应用（Claude.app、ChatGPT.app、Gemini.app）里的图标，打包时自动提取；没装官方应用的电脑（包括 Windows）从官方下载：Claude 是 claude.ai 上的应用图标，ChatGPT、DeepSeek、GLM 是官方 GitHub 账号的头像，Gemini 是 Google 官方的图标。都取不到的话，会用内置的简笔头像。

## 动手权限（每个群单独设置）

| 选项 | Claude | ChatGPT |
|---|---|---|
| 项目内放手干（默认） | 自动接受改文件；命令在沙盒里运行，只能写项目文件夹，联网只能访问 npm、PyPI、GitHub 这类开发网站 | Codex `workspace-write` 沙盒，只能写项目文件夹，可以联网 |
| 完全放开 | `--dangerously-skip-permissions` | `--dangerously-bypass-approvals-and-sandbox` |
| 只读讨论 | 只能读文件、搜索 | Codex `read-only` 沙盒 |

DeepSeek、GLM 借 Claude Code 干活，权限和 Claude 那一列一样；Gemini 的权限见上面的「Gemini（Google）」。

## 数据放在哪

- 聊天记录和会话：`~/.clawchat/`（每个群一个文件夹，`messages.jsonl` 存消息，`state.json` 存每位成员的会话 id）
- 服务日志：`~/.clawchat/server.log`
- 建群时项目文件夹留空的话，会自动建在 `~/ClawChatProjects/群名`

## 开发

```sh
npm test        # 调度逻辑的单元测试（用假的 AI，不花额度）
npm start       # 启动本地服务（端口 7317，可用 CLAWCHAT_PORT 修改）
npm run app     # 重新生成 ClawChat.app
```

- `server.js`：本地 HTTP 服务，界面通过 SSE 接收实时消息
- `lib/hub.js`：群聊调度（谁接话、接力、轮数上限、停止）
- `lib/agents.js`：驱动 `claude -p --output-format stream-json` 和 `codex exec --json`，用 `--resume` / `exec resume` 续上会话；DeepSeek、GLM 也走 `claude -p`，只是换了接口、Key 和配置目录（见 `lib/providers.js`）；Gemini 在 `lib/gemini.js`（API）和 `lib/antigravity.js`（订阅）
- `public/`：界面
- `mac/`：原生外壳（WKWebView）和图标。图标原图是 `mac/icon-art.jpg`（用 ChatGPT 生图画的），换图后运行一次 `swift mac/make-icon.swift --windows`，更新仓库里的网页图标和 Windows 图标
- `windows/`：Windows 的安装脚本（`install.ps1`，由根目录的 `Install-Windows.cmd` 启动）、启动器（`launch.js`：起后台服务、用 Edge 应用模式开窗口）和图标。`install.ps1` 要存成带 BOM 的 UTF-8，`ClawChat.vbs` 要存成 UTF-16，不然中文会乱码

移动这个项目文件夹之后，要重新运行一次 `npm run app`，因为应用里记录的是项目的绝对路径。
