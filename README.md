# ClawChat

本地 AI 群聊：你、Claude（Claude Code）和 GPT（Codex）在一个群里，一起在你的项目文件夹里干活。

- 全部跑在你自己的电脑上，用你已经登录的 Claude Code 和 Codex 账号，不经过任何第三方服务器。
- 没有第三方依赖，只需要 Node.js 22+、Claude Code、Codex。

## 打开

双击「应用程序」里的 **ClawChat**。关掉窗口不会退出，两位可以在后台继续干活；按 ⌘Q 才是真正退出，正在干的活也会一起停掉。

不想用应用窗口的话，也可以在这个文件夹里运行 `npm start`，然后用浏览器打开 http://127.0.0.1:7317 。

## 怎么用

- **点名**：`@Claude`、`@GPT`、`@所有人`。输入 `@` 会弹出成员菜单，比如打 `@c` 就会出现 Claude，按 Enter 或 Tab 填进去。不点名或者 @所有人 时，默认**两位同时开工**，各自都知道对方也在干，需要对结果时会互相 @。输入框上方的「不 @ 时」可以改成「两位依次回答」（后答的能看到前一位说了什么），或者只发给其中一位。
- **接力**：两位可以互相 @，对方会被叫醒接着干活。你不说话时，连续接力到设定的轮数就自动停下来，等你发话。
- **图片**：点「图片」按钮，或者直接粘贴（⌘V）、拖进窗口。两位都能看到图片。HEIC 格式、太大或尺寸太大的图会自动转成 JPG。
- **私聊**：
  - 你找它：在群里点某位的头像（或右上角的头像），就能私聊它，另一位看不到。它记得群里的所有事，你在私聊里定的事，它可以直接去群里落实。
  - 它找你：觉得另一位的安排不合理，它可以直接在群里说，也可以私下找你。私聊会出现在左侧，标着「私聊 · 群名」。
  - 实现方式：AI 把只给你看的话写在 `<私聊老板>…</私聊老板>` 里；你私聊它时，它的回复默认也是私聊，要公开就写在 `<群聊>…</群聊>` 里。这些标签你看不到，ClawChat 会自动分拣。
- **分身**：某位正在群里干活时你私聊它，不用等它干完——ClawChat 会复制一份它当前的记忆，开一个「分身」马上回你（消息上标着紫色的「分身」）。分身只能看、不能改文件，免得和手上的活打架；你让它动手的话，它会说干完手上的活就去做。本体干完后会看到分身聊了什么，答应过的事接着做，不会重复回复。
- **单聊**：新建聊天时只勾选一位成员，就是和它单独聊。
- **停止**：谁在干活，输入框上方就显示「停止 Claude」或「停止 GPT」；两位都在干时，还会多一个「全部停止」。只停一位不影响另一位；每个「正在干活」的气泡里也有自己的「停止」。它们启动的命令也会一起停掉。
- **回复**：鼠标移到一条消息上，点旁边的回复按钮。回复 GPT 的消息时只有 GPT 回答，回复 Claude 的消息时只有 Claude 回答；回复时又 @ 了别人，就按 @ 的来。你的消息上会带着被回复的原话，点一下就能跳回去。
- **过程**：每条回复下面的「过程」可以展开，看它跑了哪些命令、改了哪些文件；正在干活时也能点「展开过程」实时看全部步骤，GPT 的思考摘要会以 💭 显示。
- **[PASS]**：跟自己无关的消息，它们会回 [PASS]，群里不显示。

## 记忆

- 退出再打开，所有聊天记录、私聊和图片都还在。
- 两位各自接着原来的会话（Claude 用 `--resume`，Codex 用 `exec resume`），记得之前聊过什么、做过什么。会话找不到时，会带上最近 40 条聊天记录开一个新会话。
- 退出时还在干活的那一轮，下次打开会提示「被打断了」。再叫它一声，它会先看看做到哪了，再接着做。
- 出错的那一轮不算处理过，下次叫到它时，会把没处理的消息重新交给它。
- **上下文满了**：Claude Code 和 Codex 快满时会自己压缩，一般不用管。万一还是报「上下文满了」，ClawChat 会自动给它换一个新会话，带上最近 40 条聊天记录接着干，并在群里说一声；更早的完整记录会写成一个文件给它看，里面只有它本来就能看到的内容（群聊 + 它自己和你的私聊），另一位和你的私聊不在里面。换了新会话还超的话，多半是这次一下子发了太多内容，会提示你分几次发。

## 模型

- 聊天窗口顶部有两个模型切换框（Claude 的和 GPT 的），随时可以换，从下一轮开始生效。换模型不影响记忆，会话照样接着。
- 模型旁边是**思考强度**：Claude 有 低 / 中 / 高 / 超高 / 最高 五档；GPT 的档位取决于模型，多数是 低 / 中 / 高 / 超高 / 最高 / 极限（极限会自动把任务拆给帮手），Luna 系列没有极限。「默认」跟随 Claude Code / Codex 自己的设置。换了模型、新模型又不支持原来的强度时，会自动退回默认。
- 切换后群里会提示一条，每条回复的名字旁边会标出这次实际用的模型，比如 `Fable 5.1`、`GPT-6-Astra`。
- Claude 可选 Fable、Opus、Sonnet、Haiku，用的是别名，Claude Code 会自动对应到最新版本。
- GPT 的列表直接读 Codex 的模型目录，只列出你账号能用的模型。

### 出了新模型（比如 GPT-7）怎么用

1. **等它自己出现**：ClawChat 每 5 分钟重新读一次模型目录，你切回窗口时也会读一次。只要 Codex 的目录里有了新模型，下拉框里就会多出来，不用重启。
2. **没出现就点「更新」**：新模型常常要新版本的命令行才看得到。点左下角 Codex（或 Claude Code）旁边的「更新」，更新完列表会自动刷新。
3. **还没有就自己填**：选下拉框最下面的「自定义模型…」，填上模型名。ClawChat 会先用它试着回一句话：能用才切换，用不了会显示原因，不会把群弄坏。

## 外观

- 侧栏底部可以切换「浅色 / 深色 / 自动」，自动就是跟随系统。
- 界面参考 macOS 的「信息」App：侧栏半透明毛玻璃，窗口没有标题栏，顶部空白处可以拖动窗口，双击可以缩放。

## 设置与在线升级

点左下角的「设置」，或者按 ⌘,：

- **通用**：主题（浅色 / 深色 / 跟随系统），聊天记录放在哪。
- **程序与模型**：Claude Code、Codex 的版本，「更新」按钮，以及现在能用的所有模型。
- **更新**：当前版本，「检查更新」和「立即升级」。升级会从 GitHub 拉取最新代码、重新打包，然后自动重启。聊天记录和记忆不受影响；正在干的活重启后会提示你接着做。有新版本时，「设置」旁边会亮一个小红点。

菜单栏里的「ClawChat → 检查更新…」也可以直接检查。

## 装到另一台 Mac

需要 Node.js 22+、Xcode 命令行工具（`xcode-select --install`），以及登录好的 Claude Code 和 Codex。

```sh
gh repo clone Lenka0605/ClawChat   # 或 git clone
cd ClawChat
npm run app                         # 生成 /Applications/ClawChat.app
```

Claude 和 ChatGPT 的头像用的是本机官方应用（Claude.app、ChatGPT.app）里的图标，打包时自动提取；没装官方应用的话，会用内置的简笔头像。

## 动手权限（每个群单独设置）

| 选项 | Claude | GPT |
|---|---|---|
| 项目内放手干（默认） | 自动接受改文件；命令在沙盒里运行，只能写项目文件夹，联网只能访问 npm、PyPI、GitHub 这类开发网站 | Codex `workspace-write` 沙盒，只能写项目文件夹，可以联网 |
| 完全放开 | `--dangerously-skip-permissions` | `--dangerously-bypass-approvals-and-sandbox` |
| 只读讨论 | 只能读文件、搜索 | Codex `read-only` 沙盒 |

## 数据放在哪

- 聊天记录和会话：`~/.clawchat/`（每个群一个文件夹，`messages.jsonl` 存消息，`state.json` 存两位的会话 id）
- 服务日志：`~/.clawchat/server.log`
- 建群时项目文件夹留空的话，会自动建在 `~/ClawChatProjects/群名`

## 开发

```sh
npm test        # 调度逻辑的单元测试（用假的 AI，不花额度）
npm start       # 启动本地服务（端口 7317，可用 CLAWCHAT_PORT 修改）
npm run app     # 重新生成 ClawChat.app
```

- `server.js`：本地 HTTP 服务，界面通过 SSE 接收实时消息
- `lib/hub.js`：群聊调度（谁接话、接力、轮数上限、停止）
- `lib/agents.js`：驱动 `claude -p --output-format stream-json` 和 `codex exec --json`，用 `--resume` / `exec resume` 续上会话
- `public/`：界面
- `mac/`：原生外壳（WKWebView）和图标

移动这个项目文件夹之后，要重新运行一次 `npm run app`，因为应用里记录的是项目的绝对路径。
