      ChatGPT

      会话（记忆） 记了多少、什么时候该换

      「记忆」是它这个会话里记着的全部内容，每一轮都要整个带上，所以越多越慢。换新会话时可以选谁来把情况重新交代给它（默认是上一个给它派活的 AI，也可以让它自己看记录，或者你自己来说）；项目文件夹里的文件都还在。ChatGPT 看过的每张图（包括它自己做的图）都会整张存进会话，图片到 8MB 时群里也会提醒你换。

      通用

      外观

      「自动」会跟着系统外观在浅色和深色之间切换。

      语言

      界面语言

      「跟随系统」时，系统是中文就用中文，否则用英文。换语言后，AI 也会用这种语言回复。

      手机访问 通过 Tailscale，在外面用手机看这个群聊

      默认项目文件夹

      退出再打开，聊天记录、私聊和大家的记忆都会保留。全部只存在这台电脑上。

      通知

      后台运行

      退出 ClawChat关掉窗口后 ClawChat 还在后台运行，大家可以接着干活；点这里才会彻底退出，正在干的活也会停下（下次打开会提示接着做）。

      程序

      用的都是你电脑上装好的官方程序。新模型常常要新版本的程序才看得到；ClawChat 每 5 分钟会自动重新读一次模型列表。

      DeepSeek

      API Key

      在 platform.deepseek.com 创建 API Key（要先充值一点余额）。DeepSeek 借 Claude Code 干活，所以要装好 Claude Code，但不用登录 Claude 账号。Key 只存在这台电脑上。

      GLM

      API Key

      在 bigmodel.cn 创建 API Key。GLM 借 Claude Code 干活，所以要装好 Claude Code，但不用登录 Claude 账号。Key 只存在这台电脑上。

      Gemini

      API Key

      订阅（Google AI Pro / Ultra）：Key 留空，用 Antigravity CLI 跑，消耗订阅额度，用完要等恢复。个人订阅已经不能再用 Gemini CLI。

      API：填 Gemini API Key（在 Google AI Studio 创建），按用量计费。Key 只存在这台电脑上。
