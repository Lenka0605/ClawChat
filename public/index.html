ClawChat

    把 Claude、ChatGPT 和 DeepSeek 拉进一个群

    你在群里说话，它们一起干活：分工、互相 @、在你的项目文件夹里改代码、跑命令。有话也可以私下找你。

    或者先单独聊聊：
    松开就把图片加到消息里

    新建聊天

    成员 只选一位就是单聊

    基本信息

    项目文件夹

    它们会在这个文件夹里读写文件、运行命令。

    动手权限

    Windows 上 Claude 和 DeepSeek 跑命令没有沙盒：「项目内放手干」时，命令能不能只动项目文件夹，要靠它们自觉（已经在提示词里交代过）。ChatGPT 有自己的沙盒。

    协作

    模型 聊天窗口顶部也能随时切换

    Claude 思考
    ChatGPT 思考
    DeepSeek 思考

    速度 目前只有 ChatGPT 能开快速模式

    ChatGPT

    会话（记忆） ChatGPT 做图做多了要换

    让 ChatGPT 做图时要留意：它每看一张图（包括它自己做出来的图），都会把整张图存进会话，之后每一轮都要整个重新发一遍。图片攒到 15MB 左右（大约看过 4～6 张大海报），它就会慢到像卡住一样。ClawChat 会帮你盯着：到 8MB 会在群里提醒，并附上「换新会话」按钮。换了以后，上一个给它派活的 AI（比如 Claude）会先把情况重新交代给它，再让它接着干；项目文件夹里的图和文件都还在。一批图做完、开始下一批之前，主动换一次最省心。

    通用

    外观

    「自动」会跟着系统外观在浅色和深色之间切换。

    存储

    聊天记录和图片
    默认项目文件夹

    退出再打开，聊天记录、私聊和大家的记忆都会保留。全部只存在这台电脑上。

    通知

    后台运行

    退出 ClawChat关掉窗口后 ClawChat 还在后台运行，大家可以接着干活；点这里才会彻底退出，正在干的活也会停下（下次打开会提示接着做）。

    程序

    用的都是你电脑上装好的官方程序。新模型常常要新版本的程序才看得到；ClawChat 每 5 分钟会自动重新读一次模型列表。

    DeepSeek

    API Key

    在 platform.deepseek.com 创建 API Key（要先充值一点余额）。DeepSeek 借 Claude Code 干活，所以要装好 Claude Code，但不用登录 Claude 账号。Key 只存在这台电脑上。
